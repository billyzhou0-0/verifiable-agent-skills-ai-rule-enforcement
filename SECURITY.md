# Security Policy（安全说明）

## Reporting a vulnerability（在哪里报告漏洞）

If you find a security issue in this project — a vulnerability, a leaked credential, or malicious code — please report it. / 如果发现本项目存在安全问题——漏洞、泄露的密钥或恶意代码——请报告。

- **Preferred: GitHub Private Vulnerability Reporting / 首选：GitHub 私密漏洞报告** — click **Report a vulnerability** on the **Security** tab of this repository. It is private — only the maintainer can see it. / 点击本仓库 **Security（安全）** 标签页的 **Report a vulnerability（报告漏洞）** 按钮——私密通道，只有维护者能看到。
- Direct link / 直达链接：https://github.com/billyzhou0-0/verifiable-agent-skills-ai-rule-enforcement/security
- If private reporting is not available, open a GitHub Issue with the **security** label / 如果私密通道不可用，开一个带 **security** 标签的 GitHub Issue：https://github.com/billyzhou0-0/verifiable-agent-skills-ai-rule-enforcement/issues
- If the issue involves credentials or secrets, do **not** post them publicly — describe the location only, and we will follow up privately. / 如果涉及密钥或凭据，**不要**公开发布内容——只描述位置，我们会私下跟进。
- We take every report seriously and will respond as soon as possible. / 我们会认真对待每份报告并尽快回复。
