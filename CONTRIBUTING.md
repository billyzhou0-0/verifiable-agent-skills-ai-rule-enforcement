# Contributing（贡献指南）

Thanks for your interest in this project! / 感谢你关注本项目！

## Ways to contribute（参与方式）

- **Report a bug or problem / 报告问题**：open a GitHub Issue with reproduction steps / 开 Issue 并附复现步骤
- **Suggest an improvement / 提建议**：open an Issue or start a discussion / 开 Issue 或发起讨论
- **Fix something / 修东西**：fork this repo, make your change, submit a Pull Request / fork 本仓库，修改后提交 Pull Request

## Guidelines（准则）

- **Verifiability is the core value / 可验证是本项目的核心价值** — every claim needs evidence (a source, a command, a file). 每条声称都要有证据（来源/命令/文件）。
- **No fabrication / 不编造** — unknown is marked 【待核实】(to be verified), never invented. 查不到就标【待核实】，绝不编造。
- Skill content is written in Chinese; READMEs are bilingual (EN+CN). / 技能内容为中文；README 中英双语。
- Keep changes small and reviewable. / 改动保持小而可审。
- MIT licensed. / MIT 许可。

## Getting started（快速开始）

1. Fork the repository / fork 仓库
2. Create a branch for your change / 为你的改动建分支
3. Make your change, and update `CHANGELOG.md` / 做出修改，并更新 `CHANGELOG.md`
4. Submit a Pull Request with a clear description / 提交带清晰描述的 Pull Request
