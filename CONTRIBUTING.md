# Contributing（贡献指南）

Thanks for your interest in this project! Here is how to contribute. / 感谢关注本项目！以下是参与方式。

## Ways to contribute（参与方式）

- **Report a bug / 报告问题**：open an Issue with reproduction steps (what you ran, what you saw). / 开 Issue 并附复现步骤（跑了什么、看到了什么）。
- **Suggest an improvement / 提建议**：open an Issue or start a discussion. / 开 Issue 或发起讨论。
- **Fix something / 修东西**：fork the repository, make your change, submit a Pull Request. / fork 仓库，做出修改，提交 Pull Request。

## Pull request process（PR 流程）

1. Fork the repository and create a branch for your change. / fork 仓库并为改动创建分支。
2. Make your change — keep it small and reviewable. / 做出修改——保持小而可审。
3. Update `CHANGELOG.md` for any user-facing change. / 用户可见的变更请更新 CHANGELOG.md。
4. Every claim in your change needs evidence: a source, a command, or a file. If you can't produce evidence, it didn't happen. / 改动中的每条声称都要有证据（来源/命令/文件）。给不出证据 = 没发生。
5. Submit the Pull Request with a clear description. / 提交带清晰描述的 Pull Request。

## Guidelines（准则）

- **No fabrication / 不编造**：unknown is marked 【待核实】(to be verified), never invented. / 查不到就标【待核实】，绝不编造。
- **Don't commit secrets or personal data / 不要提交密钥或个人数据**：check for API keys, tokens, and private information before pushing. / 推送前检查 API key、token 和私人信息。
- Skill bodies are written in Chinese; READMEs are bilingual (EN+CN). / 技能正文为中文；README 中英双语。
- MIT licensed. / MIT 许可。
